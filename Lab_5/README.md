# Практична робота 5 · Варіант 6

FleetStock — PHP вебзастосунок для контролю запасів комплектуючих автопарку. Дані зберігаються у MySQL, інтерфейс формує сервер. Локальне навчальне середовище для одного оператора.

## Запуск через Docker

Потрібні Docker Desktop і вільний порт 8085. У цій папці виконайте:

```bash
docker compose up -d --build
```

Відкрийте http://127.0.0.1:8085. Перше завантаження образів потребує інтернету. База й демонстраційні дані створюються автоматично. Файли копіюються в образи, тому налаштування спільних папок Docker не потрібне. Після змін коду повторіть команду запуску. `docker compose stop` зупиняє середовище; `docker compose down` видаляє контейнери, зберігаючи іменований том бази. Не додавайте `-v`, якщо потрібні збережені дані. Ініціалізаційний SQL виконується лише для нового тому.

Демонстраційні реквізити БД у `compose.yaml` призначені для локальної роботи. Порт MySQL не публікується; вебпорт прив’язаний до 127.0.0.1. Для доступу через мережу потрібні автентифікація користувачів та окремі секрети.

## Запуск у XAMPP або MAMP

Потрібні PHP 8.3+ з PDO MySQL і MySQL 8.0.16+ (перевірки CHECK). Створіть базу `fleet_stock` з utf8mb4 і користувача з доступом до цієї бази; імпортуйте `database/init.sql` саме в цю базу. Встановіть змінні середовища `DB_HOST`, `DB_NAME`, `DB_USER`, `DB_PASS`. Коренем вебсервера має бути **public**, а не корінь проєкту. Для локальної перевірки з PHP CLI:

```bash
DB_HOST=127.0.0.1 DB_NAME=fleet_stock DB_USER=fleet DB_PASS=your_password php -S 127.0.0.1:8085 -t public
```

PHP development server призначений для локальної розробки.

## Можливості

- Каталог: створення, читання, редагування, видалення невикористаних деталей; пошук за назвою, артикулом, категорією.
- Місця зберігання: CRUD, код, назва, опис полиці або стелажа.
- Надходження, списання, переміщення з перевіркою залишку в конкретному місці.
- Журнал операцій з фільтром за деталлю та розбиттям по 20 записів.
- Попередження про низький сумарний запас: кількість від 1 до мінімуму; нуль — «Відсутні».
- Кількість обліковується у штуках, лише цілими числами. Мінімум — для деталі загалом.
- Видалення записів з історією руху заборонено. Проведений рух не редагується і не видаляється через інтерфейс. Виправлення — компенсувальною операцією з поясненням.
- Транзакції InnoDB, блокування рядка деталі, підготовлені PDO запити, HTML екранування, CSRF токени, POST/Redirect/GET.

## Структура

```text
app/bootstrap.php       PDO, сесії, CSRF, валідація, екранування
app/inventory.php       CRUD та транзакційні складські операції
public/index.php        обробка форм, маршрути, HTML подання
public/assets/          CSS, JavaScript, іконка
database/init.sql       структура, ключі, обмеження, початкові дані
Dockerfile              PHP 8.3 Apache та pdo_mysql
Dockerfile.db           MySQL 8.4 та початковий SQL
compose.yaml            запуск середовища та збереження БД
tests/domain.php        інтеграційні перевірки ізольованої БД
tests/browser.cjs       сценарії для браузерів через Playwright
```

## Перевірки

PHP syntax: `docker compose exec -T web php -l public/index.php` (аналогічно для файлів app).

`tests/domain.php` запускається через PHP контейнера лише з `DB_NAME=fleet_stock_test`. Перед запуском створіть окрему базу, надайте користувачу fleet доступ до неї та імпортуйте туди init.sql. Не використовуйте робочу базу для інтеграційних тестів.

Для `tests/browser.cjs` потрібні Node.js, Playwright і встановлений Google Chrome та Firefox для Playwright. Запуск: `node tests/browser.cjs`; шлях до Playwright можна передати через `PLAYWRIGHT_MODULE`. Сценарії створюють записи з префіксом QA, виконують рух і залишають ці записи для перевірки. Запускайте їх на копії навчальної бази. Скриншоти та протокол записуються в test-output.

## Відтворення прикладу зі звіту

1. Додайте деталь FLT-FUEL-007 «Фільтр паливний Bosch», категорія «Фільтри», мінімум 8.
2. Відредагуйте назву на «Фільтр паливний Bosch Euro 6».
3. Проведіть надходження 20 шт. у A-01, підстава «Накладна № 017».
4. Спишіть 3 шт. із A-01 на техобслуговування.
5. Перемістіть 5 шт. із A-01 у B-01. Залишок деталі: 17 шт., із них 12 у A-01 і 5 у B-01.
6. Спробуйте списати 99 шт. із A-01: сервер відхилить запит, залишки не зміняться.

У поточному локальному середовищі цей приклад уже виконано. В архіві SQL містить початкові шість деталей для повторення кроків.
